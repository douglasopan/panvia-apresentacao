# Panvia

**Uma plataforma em desenvolvimento para descobrir jogos, programas e projetos independentes.**

A Panvia reúne catálogo, páginas de produtos, imagens, vídeos, versões e devlogs. O site está disponível em [panvia.online](https://panvia.online/) e há uma prévia do aplicativo para Windows. O objetivo é aproximar quem cria de quem procura novos projetos, com informações claras sobre cada produto e sua distribuição.

Este repositório apresenta o projeto e recebe contribuições de documentação e propostas. O código-fonte é mantido privado.

## Conheça o projeto

- [Site da Panvia](https://panvia.online/)
- [Programas no catálogo](https://panvia.online/#programs)
- [Enviar uma proposta de projeto](https://panvia.online/#publish)
- [Prévia Windows review.24](https://github.com/douglasopan/panvia-releases/releases/tag/v0.5.0-native-review.24)
- [Repositório de distribuição](https://github.com/douglasopan/panvia-releases)

A prévia Windows é experimental, para Windows x64, requer WebView2 e não possui assinatura digital. Consulte as instruções e limitações da versão antes de usá-la.

## Onde estamos

| Estado | Recursos |
| --- | --- |
| Disponível | Catálogo de jogos e programas, páginas com mídia e devlogs, propostas de criadores e revisão administrativa, seleção de versões e downloads qualificados por produto. |
| Verificado com limites | Publicação da prévia Windows review.24, integridade dos pacotes e downloads das três edições de Colônia. Download e extração não comprovam instalação completa ou execução. |
| Pendente | Login Google completo, licenças operacionais de software, nova distribuição Windows com indicação da pasta extraída e validação dos fluxos de instalação e atualização por produto. |
| Planejado | Avaliações, portal de criadores, moderação e recursos de comunidade. |

O [estado atual](STATUS.md) detalha esses limites. O [roadmap](ROADMAP.md) registra as direções do projeto sem prometer datas.
